# 1. Visión General del Proyecto

**Nombre del Proyecto:** Rick and Morty Explorer
**Versión:** 1.0.0
**Fecha:** 31/12/2025

## 1.1. Propósito y Alcance

**Rick and Morty Explorer** es una aplicación web de página única (SPA) cuyo propósito principal es demostrar una arquitectura de frontend moderna, escalable y bien documentada utilizando React y Redux Toolkit.

El alcance funcional de la aplicación se centra en interactuar con la API pública de Rick and Morty para:
-   Mostrar un listado de personajes.
-   Permitir la búsqueda de personajes por nombre.
-   Ofrecer una funcionalidad para gestionar una lista de "favoritos".
-   Proporcionar una interfaz de usuario limpia y amigable con tema claro y oscuro.

Este proyecto no solo sirve como una aplicación funcional, sino también como una **plantilla de referencia** para la estructuración y documentación formal de proyectos React.

## 1.2. Objetivos del Proyecto

-   **Objetivo Funcional:** Proveer una experiencia de usuario fluida y agradable para explorar los personajes del universo de Rick and Morty.
-   **Objetivo Técnico:** Implementar una arquitectura limpia y desacoplada, separando la lógica de negocio (hooks), el estado (Redux) y la presentación (componentes).
-   **Objetivo Documental:** Generar un conjunto completo y profesional de documentación que sirva como guía para el desarrollo, mantenimiento y entendimiento del sistema.
-   **Objetivo de Calidad:** Asegurar la calidad del código mediante herramientas de linting (ESLint) y validación de tipos en componentes (PropTypes).

## 1.3. Público Objetivo

-   **Usuarios Finales:** Fans de la serie Rick and Morty que deseen explorar sus personajes.
-   **Desarrolladores de Software:** Profesionales y estudiantes que busquen un ejemplo práctico de una base de código React bien estructurada y documentada.
-   **Arquitectos de Software:** Para evaluar un modelo de arquitectura y documentación aplicable a proyectos de frontend.
