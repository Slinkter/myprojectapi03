# 2.2. Historias de Usuario

**Fecha:** 31/12/2025
**Versión:** 1.0

Este documento traduce los requerimientos funcionales a historias de usuario bajo el formato ágil "Como [tipo de usuario], quiero [objetivo] para [beneficio]".

---

### Épica: Exploración de Personajes

-   **US-01:** Como **usuario**, quiero **ver una lista de personajes al entrar en la aplicación** para **descubrir quiénes existen en el universo de Rick and Morty**.

-   **US-02:** Como **usuario**, quiero **ver un indicador visual mientras los personajes están cargando** para **saber que la aplicación está funcionando y no se ha colgado**.

-   **US-03:** Como **usuario**, quiero **escribir el nombre de un personaje en una barra de búsqueda** para **encontrar a ese personaje específico rápidamente**.

-   **US-04:** Como **usuario**, quiero **ver un mensaje claro si mi búsqueda no produce resultados** para **saber que no hay coincidencias y poder intentar otra búsqueda**.

### Épica: Gestión de Favoritos

-   **US-05:** Como **usuario**, quiero **marcar un personaje como "favorito"** para **guardarlo en una lista personal y acceder a él fácilmente más tarde**.

-   **US-06:** Como **usuario**, quiero **ver una lista con todos mis personajes favoritos** para **tener una vista consolidada de mi selección**.

-   **US-07:** Como **usuario**, quiero **poder quitar un personaje de mi lista de favoritos** para **mantener mi lista actualizada según mis preferencias**.

### Épica: Experiencia de Usuario y UI

-   **US-08:** Como **usuario**, quiero **poder cambiar entre un tema claro y uno oscuro** para **adaptar la apariencia de la aplicación a mis preferencias visuales o a la luz ambiente**.

-   **US-09:** Como **usuario**, quiero **ver un mensaje de error claro y una opción para reintentar si la aplicación no puede cargar los datos** para **entender el problema y poder solucionarlo sin tener que recargar la página manualmente**.
